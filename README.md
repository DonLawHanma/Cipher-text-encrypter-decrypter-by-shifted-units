# Caesar Cipher Tool

A simple Python command-line tool that encrypts and decrypts text using the Caesar cipher.

## How it works
Each letter is shifted by a fixed amount. Uppercase and lowercase letters are handled separately. Punctuation, spaces, and numbers are unchanged.

## Run
    python caesar_cipher.py

## Example
Shift 3:
    Hello, World! -> Khoor, Zruog!

## Limitations
This is an educational tool, not secure encryption. Caesar ciphers can be broken easily by brute force or frequency analysis.
